# 01 — Project brief

## Client / brand

**International Association of Commodity & Futures Exchanges (ACE)** — Международная ассоциация товарных и фьючерсных бирж.

Repository: `IMONsergey/client-AXE`.

> Naming discrepancy: the repository uses `AXE`, while all supplied public-facing assets use **ACE**. Until the client states otherwise, `AXE` is treated only as an internal repository codename. Public copy and logo must use ACE.

## Current stage

The website design is being developed in **Figma**. GitHub stores the project inputs and implementation requirements. Frontend implementation must follow the approved Figma layouts rather than any previous coded concept.

## Business / perception goal

The website should support the Association's ambition to become a global information infrastructure for international inter-exchange trade.

The intended perception is:

- an international market-infrastructure institution;
- a credible platform connecting exchanges and markets;
- a data-led digital product with a global operating scope;
- a premium, controlled, technically mature financial brand.
