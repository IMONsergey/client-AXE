# Реализация Figma-концепта

## Источник дизайна

Главная desktop-композиция реализована по Figma-фрейму `2:2` файла `umGeJGpPYOlwtTRgyE1qw7` (1440 × 2993 px).

Для desktop 1440 px зафиксированы размеры и координаты ключевых узлов из Figma: header, hero, блок цифр, «Об ассоциации», три карточки направлений и строка стран-участниц.

## Стек

- семантический HTML5;
- обычный CSS без Tailwind и без привязки к CMS;
- небольшой ES-module только для интерактивного глобуса;
- все используемые изображения, SVG и шрифты хранятся локально в репозитории;
- TikTok Sans и Inter Tight подключены как self-hosted WOFF2;
- COBE 2.0.1 vendored локально в `assets/vendor/cobe.js`.

## Глобус

Вместо плоского Figma-экспорта используется уже подготовленный COBE-фрагмент с тонкими дугами связей. Он сохранён как самостоятельный canvas-компонент и перекрашен под текущий макет:

- тёмно-бирюзовая сфера;
- cyan-карта и связи;
- медленное непрерывное вращение;
- линии появляются и исчезают целиком, без летящих точек/«боеголовок»;
- desktop-размер и положение соответствуют области глобуса в Figma.

## Контент

Видимый текст ограничен утверждённым реестром из `docs/PROJECT_CONTEXT.md`. Новые подписи, данные и микрокопирайтинг не добавлялись.

## Адаптив

Исходный Figma-фрейм содержит desktop-композицию. Поведение ниже 1440 px является аккуратной адаптивной экстраполяцией с двумя дополнительными диапазонами; desktop 1440 px остаётся контрольным вариантом для pixel-alignment.

## Проверка

GitHub Actions workflow `.github/workflows/qa-figma-concept.yml`:

1. проверяет отсутствие временных Figma MCP URL и Google Fonts в runtime;
2. проверяет наличие локальных ассетов и COBE runtime;
3. запускает страницу через локальный static server;
4. рендерит Chromium-скриншоты 1440 px и 390 px;
5. сохраняет Figma reference и оба runtime-скриншота в Actions artifact `visual-qa`.
