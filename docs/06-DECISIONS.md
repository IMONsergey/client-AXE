# 06 — Decision log

## 2026-08-12 — kickoff

### D-001 — Public brand naming

Use **ACE** in all public-facing design and copy. `client-AXE` remains the repository name / internal codename only.

### D-002 — Concept scope

Stage 2 is limited to the visual system demonstrated on the first desktop blocks. Do not over-design the full site before the concept is approved.

### D-003 — Visual positioning

The design must communicate **market infrastructure** rather than generic NGO / association branding.

### D-004 — Base palette

Use a light base. ACE Blue is the primary functional accent. Red and green are point signals. Cool Gray is secondary text / support color, not the dominant hero fill.

### D-005 — Data policy

Do not invent quantitative market claims. Current approved-for-concept facts are limited to the supplied `8 / 7 / ~15` values.

### D-006 — Network visual

The concept's network visualization is a visual metaphor built from the seven supplied country names. It is not a literal geographic market map and must not imply routes, memberships or legal relationships beyond client-approved data.

### D-007 — Fonts

Use Echoes Sans + Pragmatica as the intended brand families. Do not commit or distribute font binaries unless the client provides licensed webfont files.

### D-008 — Raw source archives

The supplied ZIP archives and screenshots were analyzed and normalized into repository documentation. The GitHub connector is used for source-of-truth project files; large raw uploaded binaries are not duplicated into Git history during kickoff. Production-safe derivative logo imagery used by the concept is embedded in `concept/index.html`.

## 2026-08-12 — reference synthesis clarification

### D-009 — Prototype status

The supplied homepage prototype is **content / IA only**. It is not a design reference and none of its card styling, grey hero treatment, pill tags, spacing or component appearance is protected.

Preserve the required content structure; redesign the visual system from first principles.

### D-010 — Two-layer reference model

The concept uses two reference families with different responsibilities:

- **WFE + CME Group + Gafta** → institutional strictness, grid, structure, trust, governance and international scale;
- **Stripe + Ramp + Paystand** → modern product presentation, large typography, proof metrics, platform decomposition and technological-system feeling.

Betterment + Acorns are secondary and may influence readability / pacing only.

### D-011 — Institutional shell / product core

The working formula is **institutional shell / product core**.

The global header, About, members, governance and documents should feel like an international market institution. The hero, infrastructure directions and Trade Requests should feel like a modern operating platform.

Neither layer may dominate enough to turn the site into either a legacy trade-association website or a fintech startup landing page.

### D-012 — No generic card language

Do not use the prototype's equal rounded service cards as the primary presentation of the three infrastructure directions.

Inter-exchange Links, Price Agency and Trading Platform must read as connected infrastructure layers. Prefer grid / row / system compositions with structural rules over isolated icon cards.

### D-013 — Countries are network structure, not tags

The seven supplied countries must not be presented as decorative pill tags in the concept. Use a structured network rail / matrix / node system that communicates international participation.

### D-014 — Proof hierarchy

`8 exchanges / 7 participating countries / ~15 considering membership` are first-screen proof and receive major typographic weight. They must not be relegated to small sidebar cards.
