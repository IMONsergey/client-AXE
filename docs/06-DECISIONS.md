# 06 — Decision log

## 2026-08-12 — kickoff

### D-001 — Public brand naming

Use **ACE** in all public-facing design and copy. `client-AXE` remains the repository name / internal codename only.

### D-002 — Concept scope

Stage 2 is limited to the visual system demonstrated on the first desktop blocks. Do not over-design the full site before the concept is approved.

### D-003 — Visual positioning

The design must communicate **market infrastructure** rather than generic NGO / association branding.

### D-004 — Base palette

Use a light base. ACE Blue is the primary functional accent. Red and green are point signals. Cool Gray is secondary text / support color, not the dominant hero fill.

### D-005 — Data policy

Do not invent quantitative market claims. Current approved-for-concept facts are limited to the supplied `8 / 7 / ~15` values.

### D-006 — Network visual

The concept's network visualization is a visual metaphor built from the seven supplied country names. It is not a literal geographic market map and must not imply routes, memberships or legal relationships beyond client-approved data.

### D-007 — Fonts

Use Echoes Sans + Pragmatica as the intended brand families. Do not commit or distribute font binaries unless the client provides licensed webfont files.

### D-008 — Raw source archives

The supplied ZIP archives and screenshots were analyzed and normalized into repository documentation. The GitHub connector is used for source-of-truth project files; large raw uploaded binaries are not duplicated into Git history during kickoff. Production-safe derivative logo imagery used by the concept is embedded in `concept/index.html`.
