# 13 — ACE Concept Lab v4

## Status
Five design directions prepared in one standalone HTML viewer: `concept-lab/index.html`.

This pass follows `docs/10-STRICT-PRODUCTION-RULES.md` and `design-system/DESIGN-INTELLIGENCE.md`.

## Non-negotiable content rule
All visible website copy inside every concept is taken from the supplied prototype/current source. No new marketing copy, English micro-labels, KPI, fake product data, dashboard text or invented navigation has been added.

The concept switcher is external review UI and uses only numeric labels `01–05`.

## Shared implementation rules
- one self-contained HTML concept-lab file;
- semantic HTML5 page structure inside each direction;
- clean CSS without framework/runtime dependencies;
- no JavaScript required for switching: native radio controls + CSS;
- three responsive composition modes: mobile, tablet, desktop;
- official ACE logo reused without redrawing or recolouring;
- no remote fonts until licensed corporate files are supplied;
- no glassmorphism, fake dashboards, decorative node networks, glowing borders or generic 30px card language.

## Direction 01
Public technology composition with a dominant ACE-blue geometric field. The Stripe influence is expressed through confident asymmetry, a strong colour plane, decisive type and proof integrated into the hero — not through copied Stripe assets.

## Direction 02
Institutional exchange grid. The visual system is carried by a strict 12-column structure, typography, black rules and oversized proof metrics. WFE/CME authority is stronger here, with product polish coming from spacing and responsive discipline.

## Direction 03
Product protocol. The three real strategic directions from the prototype are used as the product surface, so technological character comes from actual content rather than a fabricated dashboard.

## Direction 04
Editorial institution. Almost no decorative product UI; large editorial typography, asymmetric reading columns and restrained institutional rules carry the design. This direction tests whether ACE can feel premium through hierarchy alone.

## Direction 05
Structured exchange surface. A precise bounded hero and a single system frame for the three strategic directions create a product-grade feel using borders and grid relationships rather than floating cards.

## Donor mapping
- Stripe: art-direction confidence, hierarchy, proof proximity, spatial rhythm.
- Primer Brand: 12-column layout logic, hero anatomy, responsive composition.
- Reshaped: compact radii, restrained elevation, spacing discipline.
- Coss: compact action/control proportions and neutral surface language.
- Base UI: behaviour reference for later interactive production implementation.
- ReUI: reserved for Trade Requests form/table implementation rather than forcing application UI onto the public homepage.

## Review rule
The five directions are intentionally different in architecture, not merely colour. The next pass should select one or two strongest compositional systems and deepen them instead of averaging all five together.
