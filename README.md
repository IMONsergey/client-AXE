# client-AXE

Дизайн и будущая вёрстка сайта Международной ассоциации товарных и фьючерсных бирж.

Текущий этап: разработка пяти парных дизайн-концепций главной страницы — hero и следующий блок «Об ассоциации».

Главный документ проекта: [docs/PROJECT_CONTEXT.md](docs/PROJECT_CONTEXT.md).

Критические правила:

- только утверждённый клиентский текст, без новых слов и перефразирования;
- контентный прототип не является дизайн-референсом;
- header только в одну строку;
- светлая база и фирменные цвета ACE;
- понятная структурная композиция, без абстрактного хаоса и выдуманных интерфейсов.
