# Pattern — public site

## North star

Stripe remains the art-direction reference. Primer Brand provides the structural system underneath that ambition.

The goal is not to reproduce Stripe's proprietary graphics. The goal is to reach the same level of compositional confidence and product-grade finish using ACE content and brand assets only.

## Global page anatomy

1. header/navigation;
2. hero statement + one primary action;
3. proof/scale layer;
4. institutional explanation;
5. three strategic directions as one coherent system;
6. participant/country information;
7. document/proof object.

This follows prototype content. Do not insert new sections merely because a donor library contains them.

## Header

### Desired character

- compact;
- light;
- precise;
- visually secondary to hero;
- stable on desktop;
- clear utility separation for RU/EN and Trade Requests.

### Rules

- logo clearspace wins over dense navigation;
- avoid oversized header height;
- avoid large pill controls unless the control is genuinely pill-shaped by function;
- navigation uses spacing/alignment rather than decorative boxes;
- mobile navigation must be a real composition, not desktop links squeezed or hidden randomly.

## Hero

### Composition rule

The hero is a page composition, not a large rounded rectangle.

Use the grid to create a relationship between:

- exact prototype heading;
- exact prototype explanatory paragraph;
- exact prototype CTA;
- a non-text visual/system surface only if it improves the message.

### Visual surface rule

A right-side or full-width visual may use geometry, lines, texture, branded colour fields or abstract system structure, but:

- no fake data;
- no fake dashboard controls;
- no invented labels;
- no generic glass stack;
- no decorative node network just because “infrastructure” sounds technical.

The visual must have one clear formal idea.

## Proof metrics

The supplied `8` and `~15` metrics are high-value evidence.

Rules:

- place near the primary narrative;
- use typographic scale and alignment before containers;
- avoid giant floating proof card with shadow;
- captions stay exactly as provided in the prototype;
- do not split `8 бирж - 7 стран-участниц` into new claims unless client copy explicitly permits it.

## About block

Treat “КТО МЫ / Об ассоциации” as editorial/institutional content, not a SaaS feature section.

Possible structural devices:

- two-column grid;
- large text block + document/metrics column;
- horizontal rules;
- document record aligned to the same grid.

Avoid creating a nested card for every subpiece.

## Three strategic directions

These are related capabilities, not three interchangeable marketing cards.

Design them as a system through one of the following:

- sequential horizontal bands;
- one large composition with three aligned regions;
- alternating river sections;
- structured rows sharing one boundary/grid;
- a single product surface containing three clearly related modules.

Do not default to `repeat(3, 1fr)` cards with three coloured icons.

## Countries

Country names are content, not tags.

Do not automatically render them as pills.

Possible treatments:

- structured list;
- register rows;
- aligned typographic rail;
- grid of names separated by rules;
- map only if real approved geographic information is needed and accurately represented.

No invented relationship/network topology.

## Document

“ДОКУМЕНТ / PDF / Декларация...” should read as institutional evidence.

Recommended anatomy:

- document type/badge;
- exact title;
- clear action if an action is present/approved;
- strong alignment and restrained boundary.

A document is a valid card/record object because it is genuinely a discrete object.

## Section rhythm

Public pages should alternate between:

- open editorial space;
- structured rule/grid sections;
- occasional strong media/product surface.

Do not make every section the same white rounded container.

## Wide-screen rule

At wide desktop, increase breathing room or media scale, not font size indefinitely. Russian headline readability takes priority over visual spectacle.
