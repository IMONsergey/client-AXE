# ACE design concept v1

Static coded concept for the first desktop blocks of the ACE website.

## Intent

- institutional authority without NGO visual clichés
- market-infrastructure scale rather than a generic corporate landing page
- light base, graphite typography, restrained use of ACE blue/red/green
- proof and network scale integrated into the hero rather than hidden below the fold
- product/infrastructure semantics borrowed from modern fintech without turning ACE into a consumer app

## Preview

Open `index.html` directly or serve this folder with any static server.

## Font note

The supplied brand guide names **Echoes Sans Regular/Bold** as the primary typeface and **Pragmatica Book/Bold** as the supporting typeface. Font binaries were not included in the supplied archives, so this prototype declares those family names and falls back to Arial/Helvetica. Licensed font files should be connected only after the client provides them.

## Logo note

The header uses a small web-optimized derivative generated from the supplied official `ACE_Logo_Horizontal-2_Color.png` and embedded directly into the concept HTML. This avoids altering the underlying public logo design while keeping the concept self-contained.
